# 需求清单（REQUIREMENTS）

> 编号规则：`R-<域>-<序号>`。所有实现与验收必须能回溯到编号。
> 状态：`待确认` / `已确认` / `实现中` / `已完成`。当前全部为“已确认（文字需求）/选择器待实测”。

**已确认的硬性参数（2026-11-23）**：描述 ≤1500 字、发布图片 4 张、标题用原标题、单规格、所在地取第一个附近地址、价格 +10%（最低 +1 元）、下载包为 zip（约 10MB）、默认仅测试模式（截图代替真实发布）。

范围总览：

| 域 | 前缀 | 说明 |
| --- | --- | --- |
| 网商园采集下载 | R-DL | 登录、店铺、筛选、商品、下载、落盘、解压 |
| 闲鱼登录 | R-LG | 登录检测、自动登录、人工接管 |
| 闲鱼发布 | R-PB | 上传图片、描述、价格、所在地、提交 |
| 测试模式截图 | R-TM | 测试/真实解耦、截图存档 |
| 统一界面 | R-UI | 按钮、开关、状态、日志查看 |
| 日志 | R-LOG | 实时、结构化、脱敏、截图路径 |
| 文件结构 | R-FS | 目录约定、清单、断点 |
| 异常处理 | R-EX | 重试、暂停、人工恢复、停止 |
| 验收标准 | R-AC | 可验证的通过条件 |

---

## 1. 网商园采集下载（R-DL）

- [ ] **R-DL-01** 自动打开网商园首页，等待页面加载完成。
- [ ] **R-DL-02** 点击“用户登录”，使用配置中的账号密码完成登录；登录前不假设页面已登录。
- [ ] **R-DL-03** 登录成功后校验登录态（用户名/头像等可见标识），失败则按 R-EX 处理。
- [ ] **R-DL-04** 打开“金牌档口”入口，取前 5 家店铺（序号与名称写入日志与清单）。
- [ ] **R-DL-05** 每家店铺内筛选“30 日新品”，再筛选“男装”。
- [ ] **R-DL-06** 在筛选结果中依次进入前 3 个商品详情页。
- [ ] **R-DL-07** 商品页点击“一键下载”，等待弹窗出现。
- [ ] **R-DL-08** 在弹窗中点击“当前的详情图,主图,颜色图:”右侧的下载按钮（该行按钮，非其他行）。
- [ ] **R-DL-09** 通过 Playwright `expect_download` 捕获下载，保存原始压缩包到商品目录 `raw/`。
- [ ] **R-DL-10** 下载完成后自动解压到 `images/`，解压失败记录错误并继续下一个商品（不中断整体）。
- [ ] **R-DL-11** 为每个商品生成 `meta.json`（店铺、商品标题、原价、URL、图片数量、下载时间、状态）。
- [ ] **R-DL-12** 汇总生成 `data/products.json`，作为发布阶段唯一数据源。
- [ ] **R-DL-13** 单商品下载超时/元素缺失时重试（次数可配），仍失败标记 `FAILED` 并记录截图。
- [ ] **R-DL-14** 任意时刻响应“暂停/停止”，暂停点只允许在步骤边界，不打断进行中的下载写盘。

## 2. 闲鱼登录（R-LG）

- [ ] **R-LG-01** 打开闲鱼首页（Web 端），检测是否已登录（头像/我的等元素）。
- [ ] **R-LG-02** 未登录时自动点击登录入口，使用配置账号完成登录（若平台支持账号密码）。
- [ ] **R-LG-03** 若出现扫码/验证码/风控拦截，立即暂停并提示人工接管（R-EX-03）。
- [ ] **R-LG-04** 人工完成登录后，用户点击“已处理，继续”，系统重新校验登录态再继续。
- [ ] **R-LG-05** 登录态持久化（`storage_state` 文件），下次启动优先复用；失效再走登录流程。
- [ ] **R-LG-06** 登录过程不得输出账号密码明文到日志/界面。

## 3. 闲鱼发布（R-PB）

- [ ] **R-PB-01** 点击右侧“发布闲置”进入发布页。
- [ ] **R-PB-02** 从已下载商品中依次取待发布项（默认按店铺/商品顺序，跳过已成功项）。
- [ ] **R-PB-03** 上传图片：从商品 `images/` 中按顺序上传 **4 张**（不足 4 张则全部上传并记录）。
- [ ] **R-PB-04** 标题：使用原商品标题（清洗非法字符后，超出平台上限则截断）。
- [ ] **R-PB-05** 描述：调用 DeepSeek API 生成符合闲鱼语言风格的宝贝描述（**不超过 1500 字**），写入描述框。
- [ ] **R-PB-06** 描述内容约束：不出现外站联系方式、二维码、极限词、虚假品牌宣称；长度符合平台限制。
- [ ] **R-PB-07** 价格：基于原价按加价规则计算，填入价格字段；金额格式合法。
- [ ] **R-PB-08** 所在地：选择“附近地址”列表中的**第一个**候选地址。
- [ ] **R-PB-09** 发布前校验必填项（图片、标题、描述、价格、所在地）齐全，缺失时暂停并记录。
- [ ] **R-PB-10** 全部填写完成后调用统一的 `PublishAction.submit()`（见 ARCHITECTURE.md），由当前模式决定“截图”或“点击发布”。
- [ ] **R-PB-11** 提交后回到首页（测试模式）或等待发布成功并回到首页（真实模式），继续下一个商品。
- [ ] **R-PB-12** 单个商品发布失败时记录失败原因与截图，按重试策略处理，不阻塞后续商品（可配“失败即停”）。
- [ ] **R-PB-13** 每个商品的发布结果写入 `publish_result.json`（模式、时间、价格、描述来源、截图路径、成功/失败）。
- [ ] **R-PB-14** 发布规格为**单规格**，不创建多 SKU / 颜色分类。

## 4. 测试模式截图（R-TM）

- [ ] **R-TM-01** 界面提供“测试模式”开关，运行时默认值来自 `config.yaml`，运行中可切换（仅对**尚未提交**的商品生效）。
- [ ] **R-TM-02** 测试模式：信息填写完成、仅差点击发布时，截全页图保存为 `downloads/<店铺>/<商品>/publish_preview.png`。
- [ ] **R-TM-03** 测试模式绝不点击发布按钮，绝不产生真实帖子。
- [ ] **R-TM-04** 真实模式：点击发布并确认结果，成功/失败都要截图留档（`publish_result.png`）。**当前交付默认不启用**。
- [ ] **R-TM-05** 模式切换通过策略实现，不得在采集下载、描述生成代码中散落 `if test_mode` 分支。
- [ ] **R-TM-06** 测试模式结束后返回首页，继续下一件商品。

## 5. 统一界面（R-UI）

- [ ] **R-UI-01** 单页面包含按钮：开始下载图片、开始发布服装、暂停、继续、停止、查看后台日志。
- [ ] **R-UI-02** 包含测试模式开关（默认取配置），并显示当前生效模式。
- [ ] **R-UI-03** 显示任务总体状态（空闲/运行中/暂停/等待人工/已停止/完成/失败）与当前步骤。
- [ ] **R-UI-04** 显示进度：当前第几店第几商品、成功/失败/跳过计数、总耗时。
- [ ] **R-UI-05** 日志面板实时滚动展示（轮询增量），可暂停自动滚动、可清屏（仅清前端）。
- [ ] **R-UI-06** 人工接管提示醒目展示原因与处理建议，并提供“已处理，继续”按钮。
- [ ] **R-UI-07** 界面不展示任何敏感信息；配置项仅展示脱敏后的只读信息。
- [ ] **R-UI-08** 按钮状态随任务状态禁用/启用，防止重复启动。

## 6. 日志（R-LOG）

- [ ] **R-LOG-01** 每条日志包含：时间、模块、步骤、商品标识、状态、耗时(ms)、错误信息、文件路径、截图路径。
- [ ] **R-LOG-02** 输出三路：控制台摘要、`logs/app.log`（文本）、`logs/structured.jsonl`（结构化）。
- [ ] **R-LOG-03** 敏感字段（密码、token、cookie、API Key、手机号）统一脱敏，模板如 `***`。
- [ ] **R-LOG-04** 界面日志按时间顺序增量拉取，支持按级别/模块过滤（可选）。
- [ ] **R-LOG-05** 异常必须带堆栈摘要（不含敏感值）与当时截图路径。

## 7. 文件结构（R-FS）

- [ ] **R-FS-01** 下载根目录可配置（`downloads.root_dir`）。
- [ ] **R-FS-02** 目录层级：`downloads/<店铺序号_店铺名slug>/<商品序号_商品slug>/`。
- [ ] **R-FS-03** 商品目录内固定子结构：`raw/`（原始压缩包）、`images/`（解压后图片）、`meta.json`、`description.txt`、`publish_result.json`、测试截图 `publish_preview.png`。
- [ ] **R-FS-04** 全局清单 `data/products.json` 与运行报告 `data/report_<时间戳>.json`。
- [ ] **R-FS-05** 文件名做 Windows 非法字符清洗与长度截断（≤ 80 字符），保证路径可用。
- [ ] **R-FS-06** 重复运行不覆盖已成功数据；同一商品重跑使用 `_r2` 后缀或覆盖标记（可配）。

## 8. 异常处理（R-EX）

- [ ] **R-EX-01** 全局异常不导致进程崩溃：顶层捕获 → 记录 → 任务置 `FAILED` → UI 提示。
- [ ] **R-EX-02** 元素等待统一超时（可配）+ 自动重试（次数、退避可配）。
- [ ] **R-EX-03** 登录失败、验证码、风控、页面结构异常 → `PAUSED_HUMAN`，UI 提示人工接管，等待用户“已处理，继续”。
- [ ] **R-EX-04** 暂停：在步骤边界生效，当前动作完成后停下；停止：不再开始新商品，允许当前商品收尾或直接中断（可配）。
- [ ] **R-EX-05** 浏览器崩溃/断连：尝试重启浏览器一次，仍失败则暂停等待人工。
- [ ] **R-EX-06** 磁盘写入失败、解压失败、API 超时均有独立错误码与日志。
- [ ] **R-EX-07** 所有暂停/失败状态可恢复：保留已完成商品记录，重启后从待办继续。

## 9. 验收标准（R-AC）

| 编号 | 验收条件 | 验证方式 |
| --- | --- | --- |
| R-AC-01 | 点击“开始下载图片”后，浏览器可见地完成登录与 5 店 × 3 商品下载 | 人工观察 + `data/products.json` 有 15 条记录 |
| R-AC-02 | 每个商品目录内有 `raw/` 压缩包且 `images/` 已解压出图片 | 目录抽查 |
| R-AC-03 | 日志实时滚动，任意一条日志含时间/模块/步骤/状态/耗时，敏感信息为 `***` | 界面与 `logs/app.log` 对比 |
| R-AC-04 | 测试模式发布流程完成 15 次填写，每商品目录存在 `publish_preview.png`，且闲鱼无新增帖子 | 截图核对 + 闲鱼个人页核对 |
| R-AC-05 | 测试模式下 `publish_result.json` 标记 `mode=test`、`submitted=false` | 抽查文件 |
| R-AC-06 | 切换真实模式后，点击发布成功生成帖子并记录 `submitted=true` 与结果截图 | 闲鱼页面核对（建议先用 1 件商品验证） |
| R-AC-07 | 断网/元素缺失/验证码时任务进入暂停态，UI 提示人工，处理后能继续 | 人为制造故障 |
| R-AC-08 | 模式切换不影响下载与描述生成：测试/真实两种模式都能完整产出图片、描述、价格 | 对照运行 |
| R-AC-09 | 同一时间只有一个任务在跑，重复点击开始无效 | UI 按钮状态验证 |
| R-AC-10 | 停止后不再打开新商品页，状态最终为 `STOPPED` | 观察日志尾部 |

## 10. 非功能与合规

- [ ] **R-NF-01** 单次运行不得触发明显高频访问：所有动作带随机间隔，页面间跳转有停顿。
- [ ] **R-NF-02** 仅本机运行，Flask 默认绑定 `127.0.0.1`，不对外暴露。
- [ ] **R-NF-03** 代码可维护：选择器集中、模块分层、单文件不超过约 400 行。
- [ ] **R-NF-04** 不做验证码识别、不伪造设备指纹、不使用他人账号数据。
- [ ] **R-NF-05** 商品图片版权与平台规则由使用者自行确认；系统不隐藏风险，文档中明确提示。
